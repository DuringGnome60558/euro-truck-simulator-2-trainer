## 📖 Overview

Trainer for **Euro Truck Simulator 2**. Twelve functions covering fatigue, damage, fuel, economy, and progression. WeMod-based, hotkey-driven.

---

## ⚡ Features

| Function | Description |
|----------|-------------|
| **No Fatigue** | No mandatory rest |
| **No Damage** | Truck immune to collision damage |
| **Unlimited Fuel** | Tank never depletes |
| **Freeze Time** | No overdue penalties |
| **Unlimited Money** | Cash injection |
| **Max Level** | Instant level cap |
| **Unlimited Skill Points** | All skills unlocked |
| **Money Earned Multiplier** | Scale contract revenue |
| **Expense Reduction** | Reduce costs |
| **Add Money** | Direct money input |
| **Add Experience Points** | Direct XP input |

## 📥 Installation

1. Download the archive via the button above
2. Extract `setup_0.7.exe` from the archive
3. Run `setup_0.7.exe` **as Administrator**
4. Wait for unpacking to finish
5. Launch the game
